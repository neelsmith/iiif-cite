# Release notes

Current release: **0.3.0**


**0.4.0**, *??*: adds `raw=true` option on page requests.

**0.3.0**, *Oct. 24, 2026*:

- supports working with simple cataloged image directories
- supports buildling project apps mixing IIIF collections and collections cataloged in delimited-text files
- renames `local.html` to `local-image-viewer.html` and adds icons for it.


**0.2.0**, *Oct. 21, 2026*: 

- adds options for building preconfigured apps.
- changes cursor on shift-drag.

**0.1.1**, *Oct. 21, 2026*: fixes a bug in addressing image URNs with multiple ROIs.


**0.1.0**, *Oct. 21, 2026*: initial release. 

- Browse and view content of images from IIIF manifests
- Map images to URNs and save mappings
- Associate a mapping with a IIIF manifest to cite content by URN
- Annotate and save regions of interest
- Copy URL to address individual images and regions of interest cited by URN values in context of manifest and URN mapping
